## 产品简介

### 系统定位

IPS（BTS Intelligent Production System）是针对BHS瓦线及流水线生产线的智能化控制系统，旨在实现生产操作的统一化管理，提高设备联动效率，从而实现企业效益最大化。

### 核心能力

IPS系统将BHS瓦线与软件有机结合，具备以下核心能力：

- **简洁的操作**：统一规范化的参数设置
- **灵活的材质搭配**：支持多材质组合
- **内置算法**：独有的生产优化算法
- **实用的功能**：满足生产现场各种需求
- **稳定的性能**：可靠的3层C/S架构

### 技术架构

系统采用3层C/S数据库结构设计：

```
┌─────────────────┐
│   客户端层      │  Windows客户端程序
├─────────────────┤
│   中间服务器层  │  业务逻辑处理
├─────────────────┤
│   数据库层      │  PostgreSQL存储
└─────────────────┘
```
