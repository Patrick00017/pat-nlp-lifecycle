## 订单操作流程

### 停换操作流程

| 属性 | 值 |
|------|-----|
| 流程ID | 停换操作流程 |
| 类型 | order |
| 界面 | 生管总控界面 |
| 功能 | 暂停自动换单，使生管与CCC订单保持同步 |

**前置条件**

- CCC正在调试
- 或生管订单与CCC订单顺序不一致

**流程步骤**

```
1. 登录IPS系统
2. 点击上方导航列表中的「生管总控界面」进入生管总控
3. 判断情况：
   a) CCC调试中，不影响生管订单顺序
   b) 生管第一笔订单，CCC运行下一笔
4. 点击「停换」按钮
5. 观察生管与CCC订单状态
6. 当两者顺序一致时，点击「取消停换」按钮
```

**流程图**

```
开始
  │
  ▼
登录IPS系统
  │
  ▼
进入生管总控界面
  │
  ▼
判断是否需要停换
  │
  ├─是─> 点击停换按钮
  │         │
  │         ▼
  │    等待订单同步
  │         │
  │         ▼
  │    点击取消停换
  │         │
  └─否─> 不操作
          │
          ▼
       结束
```

**异常处理**

| 情况 | 处理 |
|------|------|
| 停换后订单仍不同步 | 检查CCC运行状态 |
| 取消停换后立即换单 | 可能存在延迟，等待刷新 |

### 强换操作流程

| 属性 | 值 |
|------|-----|
| 流程ID | 强换操作流程 |
| 类型 | order |
| 界面 | 生管总控界面 |
| 功能 | 强制切换到下一订单 |

**前置条件**

- 当前订单需要提前结束
- 或CCC当前生产订单与生管不一致

**流程步骤**

```
1. 在生管控制主界面订单列表中选中需要强换的订单
2. 点击「强换」按钮
3. 弹出选项对话框
4. 选择强换模式：
   a) 保留刀数强换：完工刀数计入下笔订单
   b) 清除刀数强换：完工刀数清零，重新累计
5. 确认执行强换
```

**流程图**

```
开始
  │
  ▼
选中订单
  │
  ▼
点击强换按钮
  │
  ▼
弹出选项对话框
  │
  ▼
选择强换模式
  │
  ├─保留刀数─> 完工刀数累加到下单
  │
  ├─清除刀数─> 完工刀数重置为0
  │
  ▼
确认执行
  │
  ▼
结束
```

**强换模式对比**

| 模式 | 适用场景 | 完工刀数处理 |
|------|----------|--------------|
| 保留刀数 | 连续生产同一规格 | 累加到下一单 |
| 清除刀数 | 规格变化 | 清零重新计算 |

## 订单管理流程

### 新增订单流程

| 属性 | 值 |
|------|-----|
| 流程ID | 新增订单流程 |
| 类型 | management |
| 界面 | 订单列表管理界面 |
| 功能 | 创建新的生产订单 |

**必填信息**

- 工号、门幅、楞型、材质
- 客户、订单号、切宽、切长
- 剖数、压线类型、压线信息

**流程步骤**

```
1. 在订单列表管理界面点击「新增」按钮
2. 弹出订单录入对话框
3. 填写必填字段
4. 系统自动计算切宽（如有压线）
5. 点击保存
6. 订单添加到未完工列表
```

---

### 修改订单流程

| 属性 | 值 |
|------|-----|
| 流程ID | 修改订单流程 |
| 类型 | management |
| 界面 | 订单列表管理界面 |
| 功能 | 修改现有订单信息 |

**流程步骤**

```
方式一：单击修改
1. 单击选中订单
2. 点击「修改」按钮
3. 弹出修改对话框
4. 修改订单信息
5. 保存

方式二：双击修改
1. 双击订单
2. 直接进入修改模式
3. 修改订单信息
4. 保存
```

**限制**

- 每次仅允许修改一笔订单

---

### 删除订单流程

| 属性 | 值 |
|------|-----|
| 流程ID | 删除订单流程 |
| 类型 | management |
| 界面 | 订单列表管理界面 |
| 功能 | 删除不需要的订单 |

**流程步骤**

```
1. 选中订单（支持批量选择）
2. 点击「删除」按钮
3. 确认删除操作
4. 系统执行删除
```

**限制**

- 首笔订单不允许删除
- 可通过系统参数自定义设置不可删除订单数

## 查询流程

### 订单查询流程

| 属性 | 值 |
|------|-----|
| 流程ID | 订单查询流程 |
| 类型 | query |
| 界面 | 订单列表管理界面 |
| 功能 | 按条件查询订单 |

**可查条件**

- 楞型、客户、材质、规格
- 订单ID、订单号、门幅
- 开始时间、结束时间
- 报表类型（未完工表/完工表）
- 完工瓦线

**流程步骤**

```
1. 在查询区域输入查询条件
2. 点击「搜索」按钮或直接回车
3. 系统返回查询结果
4. 可选：点击「导出」导出Excel
```

**报表类型**

| 类型 | 说明 |
|------|------|
| 未完工表 | 查询未完工订单 |
| 完工表 | 查询已完工订单 |
