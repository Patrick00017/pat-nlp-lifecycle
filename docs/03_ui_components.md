# UI组件详细说明

## 组件总览

| 组件名称 | 类型 | 位置 | 功能 |
|----------|------|------|------|
| 系统状态栏 | status | 右上角 | 通讯状态显示 |
| 当前生产订单信息 | display | 主区域 | 订单参数显示 |
| 接纸机状态 | display | 机台区域 | 接纸机状态 |
| 本班与本单信息汇总 | display | 汇总区域 | 生产数据统计 |
| 未完工订单列表 | list | 列表区域 | 订单列表与操作 |

---

## 系统状态栏组件

### 基本信息

| 属性 | 值 |
|------|-----|
| 组件ID | 系统状态栏 |
| 类型 | status |
| 位置 | 界面右上角 |

### 状态说明

#### CCC状态（圆点颜色）

| 状态 | 颜色 | 含义 | 处理措施 |
|------|------|------|----------|
| 正常 | 绿色 | 通讯正常 | 无需处理 |
| 异常 | 红色 | 通讯断联 | 反馈生产管理人员 |

#### CCC异常原因

| 原因 | 说明 |
|------|------|
| CCC未开机 | 启动CCC设备 |
| 通讯网络异常 | 检查网络连接 |

#### 服务端状态（圆点颜色）

| 状态 | 颜色 | 含义 | 处理措施 |
|------|------|------|----------|
| 正常 | 绿色 | 服务正常 | 无需处理 |
| 异常 | 红色 | 服务异常 | 检查服务器状态 |

#### 服务端异常原因

| 原因 | 说明 |
|------|------|
| 服务器停机/重启 | 检查服务器运行状态 |
| 服务器网络异常 | 检查网络连接 |
| 客户端网络异常 | 检查客户端网络 |

---

## 当前生产订单信息显示组件

### 基本信息

| 属性 | 值 |
|------|-----|
| 组件ID | 当前生产订单信息 |
| 类型 | display |
| 位置 | 主显示区域 |

### 显示字段

| 字段 | 数据来源 | 说明 |
|------|----------|------|
| 当前订单备注 | ERP | 订单备注信息 |
| 切长 | ERP | 订单切长规格 |
| 切宽 | ERP | 订单切宽规格 |
| 当前车速 | BHS-MDI | 实时车速 |
| 门幅 | ERP | 门幅规格 |
| 修边 | ERP | 修边宽度 |
| 材质楞型 | ERP | 材质与楞型 |
| 定量刀数 | BHS-CCC | 计划生产刀数 |
| 剩余刀数 | BHS-CCC | 剩余刀数 |
| 完工刀数 | BHS-CCC | 已完成刀数 |
| 压线 | ERP | 压线信息 |
| 剩余米数 | BHS-MDI | 剩余米数 |
| 加减刀数 | BHS-CCC | 加减刀数 |

### 数据源映射表

```
ERP → 订单基础数据
BHS-CCC → 瓦线控制数据
BHS-MDI → 车速采集数据
```

## 接纸机状态组件

### 基本信息

| 属性 | 值 |
|------|-----|
| 组件ID | 接纸机状态组件 |
| 类型 | display |
| 位置 | 机台状态区域 |

### 机台标识

| 标识 | 含义 |
|------|------|
| LS0 | 面纸接纸机 |
| MS1 | 1号机芯纸接纸机 |
| LS1 | 1号机里纸接纸机 |
| MS2 | 2号机芯纸接纸机 |
| LS2 | 2号机里纸接纸机 |

### 状态说明

#### 圆点状态（通讯）

| 状态 | 颜色 | 含义 | 处理措施 |
|------|------|------|----------|
| 正常 | 绿色 | MDI信号正常 | 无需处理 |
| 异常 | 红色 | MDI通讯断联 | 联系BHS-400处理 |

#### 纸卷状态

| 状态 | 颜色 | 含义 | 处理措施 |
|------|------|------|----------|
| 运行中 | 黄色 | 正在使用纸卷 | 无需处理 |
| 备用 | 绿色 | 备用卷已备好 | 无需处理 |
| 待备 | 红色 | 需尽快备纸 | 及时补充纸卷 |

### 显示数据

| 数据项 | 说明 |
|--------|------|
| 本批剩余 | 当前机台在运行材质+门幅剩余米数 |
| 残卷米数 | 当前纸卷剩余米数 |
| 下批材质 | 下一批材质+门幅+总米数 |

## 本班与本单信息汇总组件

### 基本信息

| 属性 | 值 |
|------|-----|
| 组件ID | 本班与本单信息汇总 |
| 类型 | display |
| 位置 | 汇总区域 |

### 显示字段

| 字段 | 单位 | 说明 |
|------|------|------|
| 总长 | m | 已完工+未完工米数 |
| 生产 | m | 已完工米数 |
| 剩余 | m | 剩余米数 |
| 平方 | m² | 已完工平方米 |
| 均速 | m/min | 平均车速 |
| 不良率 | % | 面机不良率 |
| 修边率 | % | 面积修边率 |
| 生产时间 | - | 累计生产时间 |
| 停机时间 | - | 累计停机时间 |
| 停次 | - | 累计停机次数 |

### 数据范围

| 范围 | 说明 |
|------|------|
| 本班 | 当前班组的生产数据 |
| 本单 | 当前订单的生产数据 |

## 未完工订单列表组件

### 基本信息

| 属性 | 值 |
|------|-----|
| 组件ID | 未完工订单列表 |
| 类型 | list |
| 位置 | 列表区域 |

### 显示数据

| 数据项 | 说明 |
|--------|------|
| 总计剩余米数 | 所有未完工订单剩余总米数 |
| 当前剩余 | 所选订单至结束剩余米数 |
| 预计时间 | 所选订单预计完工时间 |
| A/B | A=订单序号，B=订单总数 |
| 选中订单总长 | 当前选中订单总长度 |

### 支持的操作

| 操作 | 触发方式 |
|------|----------|
| 重传 | 选中订单后点击按钮 |
| 刷新 | 点击刷新按钮 |
| 强换 | 点击强换按钮 |
| 停换 | 点击停换按钮 |

### 右键菜单操作

| 操作 | 功能 |
|------|------|
| 选择列 | 显示/隐藏字段 |
| 列宽自适应ALL | 自动调整列宽 |
| 修改字号 | 自定义字体大小 |
