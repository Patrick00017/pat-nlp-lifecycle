## 订单操作详情

### 重传操作

| 属性 | 值 |
|------|-----|
| 操作ID | 重传操作 |
| 类型 | order |
| 界面 | 生管控制主界面 |
| 功能 | 将订单重新发送至CCC |

**操作步骤**

1. 在生管控制主界面左侧订单列表中左键选中需要重传的订单
2. 点击列表上方的「重传」按钮
3. 系统重新发送订单数据至CCC

**触发条件**

- 订单数据传输失败
- CCC未能接收到订单
- 订单状态异常

---

### 刷新操作

| 属性 | 值 |
|------|-----|
| 操作ID | 刷新操作 |
| 类型 | order |
| 界面 | 生管控制主界面 |
| 功能 | 刷新订单列表，使其与服务端的订单数据一致 |

**操作步骤**

1. 点击生管控制主界面订单列表上方的「刷新」按钮
2. 系统从服务端同步最新订单数据
3. 订单列表更新显示

**触发条件**

- 需要查看最新订单状态
- 数据不同步时手动刷新

---

### 强换操作

| 属性 | 值 |
|------|-----|
| 操作ID | 强换操作 |
| 类型 | order |
| 界面 | 生管控制主界面 |
| 功能 | 强换至下一订单 |

**操作步骤**

1. 点击生管控制主界面订单列表上方的「强换」按钮
2. 系统弹出选项对话���
3. 用户选择强换模式：
   - 「保留刀数强换」：保留当前完工刀数，计入下笔订单
   - 「清除刀数强换」：完工刀数清0，重新累计

**强换模式说明**

| 模式 | 说明 | 完工刀数处理 |
|------|------|--------------|
| 保留刀数强换 | 刀数计入下笔订单 | 累加到下单 |
| 清除刀数强换 | 刀数清零 | 重置为0 |

**应用场景**

- 当前生管第二笔订单在CCC生产，需强换第一笔订单

---

### 停换操作

| 属性 | 值 |
|------|-----|
| 操作ID | 停换操作 |
| 类型 | order |
| 界面 | 生管控制主界面 |
| 功能 | 暂停自动换单，保持生管与CCC订单同步 |

**操作步骤**

1. 在CCC进行调试时，若不影响生管订单顺序
2. 或存在生管第一笔订单，但在CCC运行下一笔的情况
3. 点击「停换」按钮
4. 暂停生管自动换单功能
5. 当生管与CCC订单顺序一致后
6. 点击「取消停换」按钮

**应用场景**

- CCC调试期间
- 生管与CCC订单不同步

---

### 刷新不动操作

| 属性 | 值 |
|------|-----|
| 操作ID | 刷新不动操作 |
| 类型 | order |
| 界面 | 生管控制主界面 |
| 功能 | 刷新订单时保持当前位置 |

**操作步骤**

2. 点击刷新按钮时，不会跳转到当前订单
