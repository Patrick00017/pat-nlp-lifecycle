## 生管总控界面

### 基本信息

| 属性 | 值 |
|------|-----|
| 模块ID | 生管总控界面 |
| 类型 | main |
| 优先级 | 高 |
| 入口 | 顶部导航按钮 |
| 目标用户 | 刀头中控用户 |

### 功能说明

生管总控界面是IPS系统的核心控制界面，主要用于：

1. **订单信息查看**
   - 当前订单备注信息
   - 当前订单规格参数（切长、切宽、门幅、材质等）

2. **机台状态监控**
   - 各机台LS0、LS1、MS1、LS2、MS2的本批剩余米数
   - 残卷米数与下批材质
   - 当前车速实时显示

3. **生产数据查看**
   - 当前班组生产数据
   - 当前订单生产数据
   - 数据项：总米数、生产米数、剩余米数、生产面积、生产均速、不良率、修边率、生产时间、停机时间、停机次数

4. **订单参数**
   - 切长、切宽、当前车速、门幅、修边
   - 材质与楞型、定量刀数、剩余刀数、完工刀数
   - 压线信息、剩余米数、加减刀数

5. **订单列表**
   - 全部订单信息展示
   - 支持拖拽查看

### 支持的操作

- 重传操作
- 刷新操作
- 强换操作
- 停换操作

## 坑机用户界面

### 基本信息

| 属性 | 值 |
|------|-----|
| 模块ID | 坑机用户界面 |
| 类型 | secondary |
| 优先级 | 中 |
| 入口 | 权限分配 |
| 目标用户 | 坑机用户(SF1/SF2/SF3) |

### 功能说明

坑机用户界面在生管总控界面基础上，增加了以下功能：

1. **芯纸备料需求显示**
   - 未完工订单芯纸最新材质备料需求

2. **里纸备料需求显示**
   - 未完工订单里纸最新材质备料需求

### 与生管总控界面的差异

| 功能 | 生管总控界面 | 坑机用户界面 |
|------|--------------|--------------|
| 芯纸备料 | 不显示 | 显示 |
| 里纸备料 | 不显示 | 显示 |

## 同步屏界面

### 基本信息

| 属性 | 值 |
|------|-----|
| 模块ID | 同步屏界面 |
| 类型 | display |
| 优先级 | 低 |
| 入口 | 横切出口位置 |
| 目标用户 | 刀头中控人员 |

### 功能说明

同步屏界面用于在横切出口位置显示生产信息：

1. **主要信息放大显示**
   - 当前订单主要信息
   - 便于刀头人员远距离查看

2. **显示内容**
   - 订单号
   - 材质
   - 尺寸
   - 车速
   - 产量

## 办公室界面

### 基本信息

| 属性 | 值 |
|------|-----|
| 模块ID | 办公室界面 |
| 类型 | management |
| 优先级 | 中 |
| 入口 | 顶部导航 |
| 目标用户 | 排单人员、跟单人员、成品仓物流人员 |

### 功能说明

办公室界面的主要功能：

1. **未完工订单显示**
   - 所有未完工订单列表

2. **预计完成时间**
   - 直接显示每笔订单的预计完工时间
   - 方便排程和物流安排

### 典型用户

| 用户类型 | 使用目的 |
|----------|----------|
| 排单人员 | 订单排程 |
| 跟单人员 | 进度跟踪 |
| 成品仓物流 | 出货准备 |

## 订单列表管理界面

### 基本信息

| 属性 | 值 |
|------|-----|
| 模块ID | 订单列表管理界面 |
| 类型 | management |
| 优先级 | 高 |
| 入口 | 工单管理模块 |
| 目标用户 | 生产管理人员 |

### 功能说明

订单列表管理界面提供全面的订单管理能力：

1. **订单查看**
   - 未完工订单列表
   - 完工订单信息

2. **标签操作**
   - 标签打印

3. **订单操作**
   - 新增订单
   - 修改订单
   - 删除订单
   - 调整顺序
   - 错位操作
   - 堆叠操作
   - 上下刀切换（双刀用户）

4. **机台调整**
   - 默认生产机台调整

5. **订单重做**
   - 完工订单重做

### 权限说明

| 操作 | 权限要求 |
|------|----------|
| 新增 | 生产管理权限 |
| 修改 | 生产管理权限 |
| 删除 | 生产管理权限（首单不可删）|
| 重做 | 生产管理权限 |
