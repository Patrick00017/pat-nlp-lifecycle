## 核心组件

### Intent分类Agent

| 属性 | 值 |
|------|-----|
| Agent ID | intent_agent |
| 功能 | 用户意图分类与模块识别 |
| 模型 | qwen3-4b (ChatLlamaCpp) |

**输入**

- 用户自然语言问题

**输出(JSON)**

```json
{
  "question": "用户原始问题",
  "intent": "界面/操作/流程",
  "module": "确切的模块名"
}
```

**意图类型**

| 意图 | 说明 | 示例模块 |
|------|------|----------|
| 界面 | 询问UI模块功能 | 生管总控界面、坑机用户界面 |
| 操作 | 询问操作使用 | 重传操作、刷新操作、强换操作 |
| 流程 | 询问操作步骤 | 停换操作流程 |

**模块映射**

| 类别 | 模块 |
|------|------|
| 界面 | 生管控制界面、生管总控界面、系统设置界面、QDM基础表界面、基础信息界面、报表管理界面、预警管理界面、工单管理界面、图形化控制界面 |
| 操作 | 停换操作、刷新操作、强换操作、重传操作 |
| 流程 | 停换操作流程 |

---

### 文档检索Agent

| 属性 | 值 |
|------|-----|
| Agent ID | doc_agent |
| 功能 | 文档检索与问答 |
| 模型 | qwen3-4b (ChatLlamaCpp) |

**输入**

- 用户问题
- 检索到的相关文档

**工作流程**

1. 从key2text中查找直接匹配的文档
2. 对未匹配问题，从向量数据库检索
3. 生成基于文档的回答

**向量数据库配置**

| 配置项 | 值 |
|--------|------|
| 向量库 | Chroma |
| Collection | bts_collection |
| Embedding | Qwen/Qwen3-Embedding-0.6B |
| Chunk Size | 1000 |
| Chunk Overlap | 200 |

---

### 知识图谱Agent

| 属性 | 值 |
|------|-----|
| Agent ID | graph_agent |
| 功能 | 模块关系查询 |
| 图谱 | NetworkX |

**输出格式**

```json
{
  "node_name": "模块名",
  "contains_arr": ["子模块列表"],
  "related_arr": ["父模块列表"]
}
```

**关系类型**

| 关系 | 说明 |
|------|------|
| contains | 包含关系 |
| 属于 | 所属关系 |

---

### 节点提取Agent

| 属性 | 值 |
|------|-----|
| Agent ID | graph_fetch_agent |
| 功能 | 从问题中提取相关图谱节点 |
| 模型 | qwen3-4b |

**输入**

- 用户原始问题
- 所有图谱节点列表

**输出**

```json
{
  "nodes": ["node1", "node2"]
}
```

## 处理流程

### Normal Stage (已知意图)

```
1. question
       │
       ▼
2. intent_agent.invoke()
       │
       ▼ 解析JSON
   {intent, module}
       │
       ▼
3. key2text.lookup(module)
       │
       ├─存在─> doc_agent.invoke()
       │              │
       │              ▼
       │         文档内容作为context
       │              │
       │              ▼
       └─不存在─> vector_store.similarity_search()
                      │
                      ▼
                 检索内容作为context
                      │
                      ▼
4. graph_agent.invoke()
       │
       ▼
5. 合并回答 = doc_output + graph_output
```

### Brain Storm Stage (未知意图)

```
1. question
       │
       ▼
2. intent="未知" 或 复杂问题
       │
       ▼
3. graph_fetch_agent.invoke()
       │
       ▼ 提取节点
   {nodes: [...]}
       │
       ▼
4. extract_upward_subgraph(nodes)
       │
       ▼ 获取子图
   subgraph_content
       │
       ▼
5. graph_summarize_agent.invoke()
       │
       ▼
6. final_answer = 节点列表 + 图谱总结
```

## 文档预处理

### 文档加载

**源文档**

- user_manual.md (BTS用户手册)

**解析方式**

- 提取###标题及其内容
- 遇到任何标题(#, ##, ###)视为内容结束

**输出**

```python
{
  "标题1": "内容1",
  "标题2": "内容2",
  # ...
}
```

### 向量化

**流程**

1. 加载markdown文件
2. 使用RecursiveCharacterTextSplitter分块
3. 使用HuggingFaceEmbeddings向量化
4. 存储到Chroma向量库

## 意图映射规则

| 问题模式 | 意图 | 模块 | 路由 |
|----------|------|------|------|
| 界面功能询问 | 界面 | 具体模块 | Normal Stage |
| 操作使用询问 | 操作 | 具体操作 | Normal Stage |
| 流程步骤询问 | 流程 | 具体流程 | Normal Stage |
| 复杂/模糊问题 | 未知 | 未知 | Brain Storm Stage |

## 响应格式

### 最终响应结构

```
回答内容 = doc_agent输出 + graph_agent输出
```

**doc_agent输出**

- 基于文档的专业回答

**graph_agent输出**

- 模块关系说明
- 包含/所属关系总结

## 故障排查

| 故障 | 原因 | 解决方案 |
|------|------|----------|
| JSON解析失败 | 模型输出格式错误 | 检查prompt或模型输出 |
| 向量库为空 | 文档未加载 | 运行init_all() |
| 图谱加载失败 | pickle文件损坏 | 重新生成图谱 |
| 模块未匹配 | key2text未加载 | 检查markdown文件 |
